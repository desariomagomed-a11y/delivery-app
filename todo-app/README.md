# To-Do List Application

✅ To-Do List app with Room Database for local storage.

## Features

✅ Local Storage (Room Database)
✅ Add/Edit/Delete Tasks
✅ Priority Levels (Low, Medium, High, Urgent)
✅ Statistics Dashboard
✅ Filter (All, Active, Completed)
✅ Material Design 3
✅ Jetpack Compose
✅ Hilt Dependency Injection

## Technology Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Database**: Room
- **DI**: Hilt
- **Architecture**: MVVM

## Requirements

- Android 5.0+ (API 24)
- Android Studio
- Kotlin 1.9+

## Build

```bash
cd todo-app
./gradlew build
./gradlew installDebug
```
